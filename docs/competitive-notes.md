# Competitive notes

**2026-09-15 PT**

Conversation leaders (not a ranking): Adobe Reader, Edge (built-in), Foxit, SumatraPDF, PDF-XChange, PDFgear. There is no trustworthy public “top downloads” table — do not invent one.

Gaps that matter for a thin viewer competing for installs: annotations/highlight, form fill, tabs/session restore, bookmarks/outline, keyboard/accessibility, signed installer + updates.

Later (not near-term): OCR, full edit, AI, cloud.

Locked post-1.1 product order: reliability/compatibility → signing/updates → tabs/session → outline → keyboard/a11y → then annotations/forms.

ClearPDF **v1.2** page-extract / print-selection does **not** jump ahead of that queue.
